# ocms 认知维护

认知是你「世界是怎么运作的」的知识——客观规律、方法论、领域知识、经验教训。判断标准见总纲「记忆模型」（一句话：客观事实/规律，不依赖用户偏好）。

## 认知从哪里来

1. **从决策中沉淀**：多次决策背后的共同规律，可以升华为一条认知。
2. **从经验教训中总结**：踩过的坑、学到的规律、验证过的方法论。
3. **从外部研究中提炼**：查资料、竞品分析、技术调研得出的结论。

## 认知存在哪里

存在 `.ocms/cognition/` 下的 md 里：

```
.ocms/cognition/
├── overview.md        # 速览：各主题 + 一句话简介（索引）
└── <主题>.md          # 某主题的认知（主题名由你自然命名）
```

- **不预设主题**：主题根据实际产生的认知「自然长出来」。
- **分门别类**：按领域、方法论、技术、产品等角度拆分。
- **客观准确**：只记验证过的事实/规律，不记臆测。

## 怎么记录

识别到新认知时：

1. 判断属于哪个主题——有对应文件则更新，没有则新建。
2. 用 `write` 写入 `.ocms/cognition/<主题>.md`，自然语言描述，带上依据和来源。
3. 维护 `.ocms/cognition/overview.md`，确保每个主题有一行简介索引。

## 认知怎么用

做事时主动参考已有认知，避免重复踩坑；需速览读 `.ocms/cognition/overview.md`，需细节读对应文件。

## 原则

- **准确优先**：只记有依据的，不脑补。
- **可追溯**：带上来源。
- **克制**：宁缺毋滥，不确定的不记。
